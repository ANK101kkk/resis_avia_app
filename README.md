# Решись Авиа — Система динамического ценообразования

Веб-приложение для прогнозирования спроса и подбора оптимальной цены авиабилетов на основе квантильных прогнозов и ценовой эластичности маршрутов.

## Использованные модели ИИ и инструменты
При разработке проекта применялись:
* **Модель ИИ:** Google Gemini (Flash 3.8, Hydrogen 4) — использовалась для декомпозиции задачи, проектирования клиент-серверной архитектуры, поэтапной генерации и отладки кода бэкенда, фронтенда и Docker-конфигурации.
* **Среда разработки и контроль версий:** Visual Studio Code, Git, GitHub.
* **Контейнеризация и хостинг:** Docker (`python:3.11-slim`), облачный сервер Ubuntu (TimeWeb Cloud).

## Стек технологий
* **Backend:** Python 3.11, FastAPI, Uvicorn, Pydantic, pandas
* **База данных и безопасность:** SQLite (`sqlite3`), хеширование паролей SHA-256 с солью, токен-аутентификация (`Authorization: Bearer <token>`)
* **Frontend:** HTML5, Bootstrap 5, Vanilla JavaScript (Fetch API), Chart.js
* **Деплой:** Docker

## Реализованный функционал
* **Регистрация и авторизация:** создание учётной записи, вход в систему, хранение сессии и защита эндпоинта `/api/predict` проверкой токена.
* **Расчёт спроса и продаж:** вычисление желаемого количества пассажиров (`desired`) и прогноза фактических продаж (`sold`) с учётом вместимости самолёта (`seats`).
* **Визуализация по квантилям:** интерактивный комбинированный график Chart.js (спрос по сценариям от `0.1` до `0.9` с выделением медианы `0.5` и пунктирной линией вместимости борта).

## Структура репозитория
* `main.py` — серверная часть на FastAPI (логика расчёта спроса, работа с CSV и SQLite, авторизация, раздача фронтенда).
* `index.html` — клиентский интерфейс (форма входа/регистрации, форма параметров рейса, карточки показателей и график).
* `routes.csv` — справочник маршрутов (базовые цены, эластичность спроса, допустимые ценовые диапазоны).
* `my_forecast.csv` — прогноз базового спроса по квантилям на период с `2026-06-01` по `2026-07-01`.
* `requirements.txt` — список зависимостей Python.
* `Dockerfile` / `.dockerignore` — файлы для сборки и запуска Docker-контейнера.

## Запуск проекта

### Вариант 1. Через Docker (на сервере или локально)
```bash
docker build -t resis-avia .
docker run -d --name resis-avia-container --restart unless-stopped -p 80:80 resis-avia
```
После запуска приложение доступно по адресу `http://localhost` или по публичному IP-адресу сервера.

### Вариант 2. Локальный запуск (Python 3.11+)
```bash
pip install -r requirements.txt
python -m uvicorn main:app --reload
```
После запуска откройте в браузере `http://127.0.0.1:8000` (интерактивная документация API Swagger доступна по адресу `http://127.0.0.1:8000/docs`).
